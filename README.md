# 💈 Barbearia

Um projeto web de uma landing page para uma barbearia. O objetivo deste site é apresentar os serviços do estabelecimento, exibir o ambiente e facilitar o contato para agendamentos.

## 🚀 Tecnologias Utilizadas

Este projeto foi desenvolvido utilizando as seguintes tecnologias:

- **HTML5:** Estruturação semântica do conteúdo.
- **CSS3:** Estilização, layout e design responsivo.
- **JavaScript:** Comportamentos interativos e manipulação do DOM (como menus mobile, animações ou validações).
- **Git:** Versionamento de código.

## 🌟 Funcionalidades

- Design totalmente responsivo (adapta-se a celulares, tablets e computadores).
- Elementos interativos na interface para melhor experiência do usuário.
- Seção detalhada dos serviços oferecidos e tabela de preços.
- Informações de contato, horários de funcionamento e localização.
